[transcripts/killer-sh/EXAM-DRAFT-13-25.md · Q07] wrong

[transcripts/killer-sh/EXAM-DRAFT-13-25.md · Q09] wrong
  problem: Kubernetes v1.36 kubeadm defaults to etcd 3.6.8. In etcd 3.6, `etcdctl snapshot restore` was removed; `etcdctl` takes the online snapshot and `etcdutl` performs the offline restore. Endpoint and TLS flags apply to the online save, not the offline restore. For Kubernetes consumers, etcd 3.6 also recommends a revision bump marked as compacted so informer caches cannot remain at revisions that disappeared during the restore.
  fix:     Add to context: `The static Pod uses etcd 3.6.8 and etcdutl is installed on the master.` Replace steps 2 and 4 with: `2. Validate the snapshot with etcdutl snapshot status /opt/exam/09/snapshot.db; a non-empty file check alone is not an integrity check. 4. Restore offline with etcdutl snapshot restore /opt/exam/09/snapshot.db --data-dir=/var/lib/etcd-restored --bump-revision=1000000000 --mark-compacted. Do not pass endpoint or TLS flags to etcdutl.` If the provisioned exam image deliberately uses etcd 3.5 instead, state that version and still prefer `etcdutl`; only 3.5 retains the deprecated `etcdctl` restore command.
