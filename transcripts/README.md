## Curriculum source caveats

- `20-understanding-coredns-nodelocal-dnscache-VcWpZoRAQXE.txt` covers CoreDNS
  basics, Services, the Corefile, and cluster lookups. Its transcript does not
  substantively cover NodeLocal DNSCache or the `ndots` performance claim from
  the supplied description.
- `24-api-priority-fairness-flow-control-Tps4eAjuCr8.txt` is a Kubernetes 1.18
  era talk and explicitly describes APF as alpha. Current upstream behavior and
  API fields must override its feature-state claims.
- `17-kube-proxy-iptables-ipvs-lkXLsD6-4jA.txt` compares iptables and IPVS but
  predates the modern nftables mode. It is historical architecture input, not
  a current backend recommendation.
- `18-liberating-kubernetes-kube-proxy-iptables-bIRwSIwNHC0.txt` describes
  Cilium eBPF connection-tracking maps. The supplied claim that eBPF bypasses
  connection tracking entirely is too broad; it bypasses the traditional
  netfilter path in the architecture shown, not the need to track connections.
- Autoscaler, disaster-recovery, and implementation-default claims are treated
  as leads to verify against the target Kubernetes and component versions, not
  as timeless facts.
- The advanced track is organized against the official CKA v1.35 curriculum.
  DRA, MemoryQoS, pod-level resources and coordinated leader election are
  especially release-sensitive and are checked against current upstream docs.
